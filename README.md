## 代表项目

- **AI 管家 · 私有化知识库问答** · 用 Ollama 调用本地模型，串起文档切分、向量化、检索和问答，提供 Web、API 与 CLI 入口。 [查看代码](https://github.com/kaotao00/-ai)
- **建筑工程智能标书平台** · 将企业文档增量导入知识库，以混合检索为依据，编排多个 Agent 协作处理标书任务。 [查看代码](https://github.com/kaotao00/-agent-)
- **泳池人员风险辅助检测** · 使用 YOLOv3 和 OpenCV 检测人员，维护逐人轨迹，用时序滑动窗口提取运动特征并输出实验性风险评分。 [查看代码](https://github.com/kaotao00/Drowning-Detector-master)
- **声誉风险监测控制台** · 用 FastAPI 对接联网搜索，将结果按规则分级，把待核验信息送入人工复核，并通过图表展示风险分布。 [查看代码](https://github.com/kaotao00/Chery-Auto-Reputation-System)
